# Fonts

Dieses Verzeichnis ist für freie, öffentlich verteilbare Font-Dateien gedacht.

Lizenzpflichtige, organisationsspezifische oder vertrauliche Fonts gehören nicht in dieses Basis-Repo.
Sie können in einem externen Template-Root unter `assets/fonts/` liegen und werden von
Templates über den Pandoc-Wert `rmdedit-fonts` referenziert.
